Milionar
========

Milionar is an unofficial, free reimplementation of the game engine. It
contains no game data: you import the data from your own disc when you first
start it.

Milionar is free software under the GNU General Public License, version 3
(the file LICENSE in the install folder). Third-party parts and their licences
are listed in THIRD_PARTY_NOTICES.md and in the folder "licenses".

The installer also installs the Real-ESRGAN upscaler (folder "upscaler"; MIT
and BSD licences) and Microsoft's vcomp140.dll, the Visual C++ OpenMP runtime
the upscaler needs. vcomp140.dll is not open-source software. By installing
